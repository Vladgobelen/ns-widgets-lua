# ns-widgets-lua

Набор базовых Lua-виджетов для панели nspanel. Каждый виджет представляет собой изолированную папку с конфигурацией и скриптом логики.

## Установка

Для установки виджетов в пользовательскую директорию панели используйте скрипт установки:

```bash
# Установить все доступные виджеты
./install.sh

# Обновить существующие виджеты (не затрагивая ваши настройки в config.lua)
./update.sh
